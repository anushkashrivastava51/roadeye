Detector parameters

How detection works

The in-browser engine implements the synopsis pipeline with a classical CV detector — grayscale conversion, contrast equalisation, Sobel edge energy, adaptive dark-region thresholding, connected-component labelling and shape analysis — then classifies each region as pothole, crack or waterlogged patch. In the full project this stage is replaced by the trained YOLO weights behind the same API contract, so the rest of the system is unchanged.

Live survey mode

Streams the device camera, samples frames on an interval, runs the detector on each and logs geo-tagged defects automatically — the continuous-monitoring mode described in the synopsis.
